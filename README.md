# FamilyHub — Arisan & Family Network

Aplikasi arisan keluarga: iuran, pengocokan digital yang transparan, silsilah, keuangan, agenda, pengumuman, galeri, dan laporan.

**Stack:** HTML/CSS/JS statis · Vercel Functions (Node 20) · Supabase (Postgres + Storage) · GitHub.

**Mulai di sini → [docs/PANDUAN.md](docs/PANDUAN.md)** (panduan lengkap GitHub → Supabase → Vercel).

Ringkas: jalankan `supabase/schema.sql` di Supabase, isi 5 environment variable di Vercel (lihat `.env.example`), deploy dari GitHub, lalu buka situs untuk membuat admin.
